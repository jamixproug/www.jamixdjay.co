# JAMIX PRO UG Website

A premium responsive front-end website built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — complete website structure and content
- `style.css` — responsive styling, animations, dark mode
- `script.js` — navigation, theme toggle, portfolio filtering/modal, blog search/filter, forms and back-to-top

## Run locally
Open `index.html` in a browser.

## Deploy to Render
For a static site:
1. Upload these files to a GitHub repository.
2. In Render, create a **Static Site**.
3. Connect the GitHub repository.
4. Build command: leave blank.
5. Publish directory: `.`
6. Deploy.

## Before publishing
Replace:
- `+256 000 000 000`
- `hello@jamixproug.com`
- WhatsApp number in the `wa.me` link
- social media `href="#"` links
- demo portfolio/news content
- Google Maps location if a different address should be shown.

The contact form is front-end only. To receive real submissions, connect it to your backend/email service or a form provider.
